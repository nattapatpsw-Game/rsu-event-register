# P6 ขั้น Deploy

> **localhost:3000 ไม่ใช่อินเทอร์เน็ต** — `localhost` แปลว่า "เครื่องนี้"
> ส่งลิงก์นี้ให้เพื่อน เขาจะเปิดไม่ได้ หรือไปเจอเว็บของเขาเองแทน

---

### P6-1 · ตรวจก่อน push ★ ทำก่อนเสมอ

**ใช้ตอน:** ก่อนสร้าง repository บน GitHub

```text
ตรวจให้ฉันก่อน push ขึ้น GitHub แล้วตอบเป็นรายการ

1. ไฟล์ .env.local อยู่ใน .gitignore แล้วหรือยัง
2. รัน git status แล้วมีไฟล์ไหนบ้างที่กำลังจะขึ้นไป — แสดงรายการทั้งหมดให้ฉันดู
3. มีไฟล์ไหนในรายการนั้นที่มีคีย์ รหัสผ่าน หรือข้อมูลส่วนบุคคลอยู่ข้างในไหม
4. มีข้อมูลผู้ลงทะเบียนจริงหลงอยู่ในโค้ดหรือไฟล์ตัวอย่างไหม

ห้ามรัน git push เอง ฉันจะรันเอง
```

**ถ้าเผลอ commit คีย์ไปแล้ว:** ลบไฟล์แล้ว commit ใหม่ **ไม่พอ** — คีย์ยังอยู่ในประวัติทุกบรรทัด
(พิสูจน์ด้วย `git log -p`) ทางแก้เดียวคือ **ไปเพิกถอนคีย์นั้นทิ้งแล้วออกใหม่**

---

### P6-2 · เตรียมตัวแปร environment ให้ครบ

**ใช้ตอน:** ก่อนกด Deploy ที่ Vercel

```text
อ่านไฟล์ .env.example แล้วบอกฉันเป็นตาราง

1. มีตัวแปรกี่ตัว ชื่ออะไรบ้าง
2. ตัวไหนเปิดเผยได้ ตัวไหนห้ามหลุด
3. ตัวไหนที่ถ้าลืมใส่แล้ว build จะผ่านแต่เว็บจะพัง

ห้ามแสดงค่าจริงของตัวแปรใด ๆ ในคำตอบ
```

**ข้อที่ลืมกันทั้งห้องทุกรุ่น:** ตั้งค่าตัวแปรใน dashboard แล้ว **ต้องสั่ง Redeploy ใหม่**
ของเก่าที่ deploy ไปแล้วจะไม่เห็นค่าที่เพิ่งใส่

---

### P6-3 · build พังตอน deploy

**ใช้ตอน:** Vercel ขึ้น Build Failed

```text
build บน Vercel ไม่ผ่าน นี่คือ build log ทั้งก้อน

[วาง build log ตั้งแต่บรรทัดแรกที่เป็นสีแดง ลงมาจนจบ]

ฉันคาดว่าจะเกิด: build ผ่านและได้ URL จริง
สิ่งที่เกิดขึ้นจริง: build หยุดที่ขั้นตอนข้างบน

อธิบายสาเหตุให้ฉันฟังก่อน ห้ามแก้โค้ด
และบอกด้วยว่าทำไมตอนรันในเครื่องถึงไม่เจอปัญหานี้
```

**สาเหตุที่เจอบ่อยที่สุด 3 อย่าง**

1. **`any` หรือ `<img>` ที่ค้างอยู่** — ในเครื่องเป็นแค่คำเตือน แต่บน Vercel ทำให้ build ล้ม
2. **ลืมตัวแปร environment** — โค้ดที่อ่าน env ตอน import จะพังตั้งแต่ตอน build
3. **ชื่อไฟล์ตัวพิมพ์ใหญ่–เล็กไม่ตรง** — Windows ไม่สน แต่เซิร์ฟเวอร์ของ host สน
   (`Page.tsx` กับ `page.tsx` คนละไฟล์กัน)

> **ห้ามแก้ด้วยการใส่ `ignoreDuringBuilds: true` ใน `next.config.ts`** — นั่นคือการปิดตาไม่ใช่การแก้

### P6-4 · deploy แล้วเว็บขาว

**ใช้ตอน:** build ผ่าน แต่เปิดเว็บจริงแล้วหน้าขาว

**ขั้นแรกเสมอ:** เปิด DevTools บน **เว็บจริง** (ไม่ใช่ localhost) แล้วดูแท็บ Console กับ Network

```text
deploy ผ่านแล้ว แต่เปิดเว็บจริงแล้วหน้าขาว

Console บนเว็บจริงขึ้นว่า:
[วางบรรทัดสีแดงทั้งบรรทัด]

แท็บ Network: คำขอที่ชื่อ [ชื่อ] ได้สถานะ [เลข]
ฉันคาดว่าจะเกิด: เห็นหน้าแรกพร้อมชื่องานและที่นั่งคงเหลือ
สิ่งที่เกิดขึ้นจริง: หน้าขาว ไม่มีอะไรเลย

อธิบายสาเหตุก่อน ห้ามแก้โค้ด
```

**ตารางแยกอาการ**

| อาการ | สาเหตุที่เป็นไปได้มากที่สุด | ทางแก้ |
|---|---|---|
| build ผ่าน เปิดแล้ว error | ลืมตั้ง env ใน dashboard | ใส่แล้ว **redeploy** |
| ตั้ง env แล้วยัง error | ยังไม่ได้ redeploy | สั่ง Redeploy |
| หน้าแรกขึ้น แต่ไม่มีข้อมูล | ยังไม่ได้รัน `db/seed.sql` | รัน SQL ใน Supabase |
| ลงทะเบียนแล้ว error 500 | RLS ปิดทางฝั่งเซิร์ฟเวอร์ด้วย | ตรวจว่าใช้ service role key จริงไหม |

### P6-5 · ตรวจเว็บจริงหลังขึ้น

**ใช้ตอน:** ได้ URL จริงมาแล้ว — ทำก่อนแจก QR ให้เพื่อน

```text
ฉัน deploy ขึ้นไปแล้วที่ [URL ของฉัน]
สร้างเช็กลิสต์ให้ฉันไล่ทดสอบบนเว็บจริง ไม่ใช่ localhost

ต้องครอบคลุม
- กติกา R1 ถึง R5 ครบทุกข้อ
- การเปิดจากมือถือ ไม่ใช่จากคอมเครื่องที่พัฒนา
- การตรวจว่าตาราง registrations ยังอ่านจากภายนอกไม่ได้
- การตรวจว่ารหัสผ่านแอดมินไม่หลุดใน View Source

เขียนเป็นรายการสั้น ๆ ที่ฉันไล่ติ๊กได้ ไม่เกิน 10 ข้อ
```

## ✔ Checkpoint ขั้น Deploy

- [ ] มี URL จริงที่เปิดจากมือถือได้
- [ ] โค้ดอยู่บน GitHub และ `.env.local` **ไม่ได้** ขึ้นไปด้วย
- [ ] ตัวแปร environment ครบ 5 ตัวใน dashboard และ **redeploy แล้ว**
- [ ] กรอกฟอร์มจากมือถือแล้วชื่อขึ้นในหน้าแอดมินจริง
- [ ] ยิง REST ของ Supabase ที่ตาราง `registrations` จากเว็บจริง แล้วไม่ได้ข้อมูล
