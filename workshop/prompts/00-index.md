# คลัง Prompt ทั้งหลักสูตร

อบรมเชิงปฏิบัติการ **AI-Assisted Coding สำหรับการพัฒนาเว็บแอปพลิเคชัน**
ศูนย์บริการวิชาการ มหาวิทยาลัยรังสิต

---

## วิธีใช้คลังนี้

- ทุก prompt **คัดลอกไปวางได้เลย** ที่ต้องแก้มีแค่จุดที่อยู่ในวงเล็บเหลี่ยม `[แบบนี้]`
- ใช้ได้ทั้งกับ **Antigravity CLI (`agy`)** และ **เว็บแชท** (ChatGPT / Gemini / Claude)
  - ใน `agy` : พิมพ์ลงไปใน terminal ตรง ๆ agent จะอ่านและแก้ไฟล์ให้เอง
  - ในเว็บแชท : ต้อง **แปะเนื้อไฟล์ที่เกี่ยวข้องไปด้วย** เพราะเว็บแชทเปิดโฟลเดอร์ของเราไม่ได้
    แล้วเอาโค้ดที่ได้มาวางในไฟล์เอง — ดูหัวข้อ "ถ้าใช้เว็บแชท" ท้ายไฟล์นี้
- prompt ชุด P3 (เขียนโปรแกรม) **ระบุชื่อไฟล์และขอบเขตไว้เสมอ** อย่าตัดบรรทัด
  "แตะได้แค่ไฟล์นี้ ห้ามแตะไฟล์อื่น" ทิ้ง — บรรทัดนั้นคือสิ่งที่กันไม่ให้ agent ไปลบงานเก่า

## 5 ประโยคที่ทำให้ prompt ทุกอันดีขึ้นทันที

เอาไปต่อท้าย prompt ไหนก็ได้ ไม่ต้องจำทั้งหมด จำ 2 ข้อแรกพอสำหรับวันนี้

1. **`แตะได้แค่ไฟล์ [ชื่อไฟล์] ห้ามแตะไฟล์อื่น`**
   กันบั๊กที่เจ็บที่สุด คือ agent ไปลบโค้ดที่หน้าอื่นเรียกใช้อยู่

2. **`อย่าเพิ่งเขียนโค้ด อธิบายให้ฉันฟังก่อน`**
   ถ้ามันอธิบายไม่ได้ แปลว่ากำลังเดา — เดาต่ออีกกี่รอบก็ไม่เจอ

3. **`ถ้าสเปกข้อไหนกำกวมจนทำต่อไม่ได้ ให้ถามฉัน อย่าเดาเอง`**
   AI ถูกฝึกมาให้ตอบเสมอ ต้องบอกตรง ๆ ว่าอนุญาตให้ถามได้

4. **`ห้ามเพิ่ม library ใหม่โดยไม่ถามฉันก่อน`**
   ทุก library ที่เพิ่มคือของที่เราต้องดูแลต่อ และเป็นจุดที่ deploy พังบ่อยที่สุด

5. **`ทำเสร็จให้รัน npx tsc --noEmit แล้วรายงานผลจริง`**
   ตัดคำว่า "น่าจะใช้ได้แล้ว" ออกจากบทสนทนา

## คำสั่งของ `agy` ที่ใช้ในวันนี้

| คำสั่ง | ใช้ตอนไหน |
|---|---|
| `agy` | เปิด agent ในโฟลเดอร์ปัจจุบัน |
| `agy --version` | ตรวจว่าติดตั้งสำเร็จแล้ว |
| `/model` | เปลี่ยนรุ่นโมเดล — งานคิดเยอะใช้รุ่นใหญ่ งานซ้ำ ๆ ใช้รุ่นเล็กประหยัดโควตา |
| `/usage` | ดูว่าใช้โควตาไปเท่าไหร่แล้ว เช็กช่วงพักเที่ยงสักรอบ |
| `/antigravity-guide` | คู่มือในตัว |
| `@` แล้วเลือกสกิล | เรียกใช้สกิลที่ติดตั้งไว้ เช่น `@[.agents/skills/frontend-design] ...` |
| กด `Esc` | หยุด agent กลางคัน เมื่อเห็นว่ามันเริ่มเดินผิดทาง — **ใช้บ่อยกว่าที่คิด** |

> **เมื่อไหร่ควรเปิด context ใหม่:** เมื่อ agent เริ่มลืมกติกา ตอบวนซ้ำ หรือแก้เรื่องเดิมไม่จบเกิน 3 รอบ
> ปิดแล้วเปิดใหม่ แล้วใช้ **P0-3** เป็น prompt แรกเสมอ

## ถ้าใช้เว็บแชทแทน `agy`

เว็บแชทไม่เห็นโฟลเดอร์ของเรา จึงต้องเปลี่ยน 3 อย่าง:

1. **แปะไฟล์ไปด้วยทุกครั้ง** — ขึ้นต้นข้อความว่า
   ```
   นี่คือไฟล์ในโปรเจกต์ของฉัน อ่านก่อนแล้วทำตามคำสั่งท้ายข้อความ

   === AGENTS.md ===
   [วางเนื้อไฟล์]

   === requirements.md ===
   [วางเนื้อไฟล์]

   === คำสั่ง ===
   [วาง prompt จากคลังนี้]
   ```
2. **ขอโค้ดเป็นไฟล์เต็ม** — ต่อท้ายว่า
   `ส่งกลับมาเป็นเนื้อไฟล์เต็มทั้งไฟล์ พร้อมบอก path ของไฟล์ ห้ามส่งมาเป็นบางส่วนหรือใส่ ...`
3. **commit ถี่กว่าเดิม** — เพราะเราเป็นคนวางโค้ดเอง วางผิดที่แล้วย้อนยากกว่า
