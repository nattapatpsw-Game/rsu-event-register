## ส่วนที่ 3 — prompt สำหรับให้ agent เขียน test ให้

```
เขียน test จากไฟล์ requirements.md เท่านั้น ห้ามอ่านโค้ดที่เขียนไว้แล้ว
ครอบคลุมกติกา R1 ถึง R5 ให้ครบทุกข้อ
ถ้าสเปกข้อไหนกำกวมจนเขียน test ไม่ได้ ให้ถามฉัน อย่าเดาเอง
ถ้าต้องติดตั้ง library เพิ่ม ให้บอกฉันก่อน อย่าเพิ่งติดตั้งเอง
```

**กับดักที่ต้องเตือนตรง ๆ**
test ที่ AI เขียนเองจากโค้ดของตัวเอง มักจะผ่านหมด เพราะมันเขียนให้ผ่าน ไม่ได้เขียนเพื่อจับผิด
วิธีกันคือ **ล็อกแหล่งข้อมูล** ให้อ่านจากสเปกอย่างเดียว แล้วเอา test ไปรันกับโค้ดที่แทรกบั๊กไว้
ถ้า test ผ่านทั้งที่บั๊กยังอยู่ แปลว่า test ใช้ไม่ได้ ไม่ใช่โค้ดถูก
